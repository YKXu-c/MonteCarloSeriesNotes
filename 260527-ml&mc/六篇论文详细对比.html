核心概念解释

MADE（Masked Autoencoder Distribution Estimator）

MADE = 掩码自编码器分布估计器

任何联合概率分布都可以分解为条件概率的乘积：

p(x1,x2,x3)=p(x1)⋅p(x2∣x1)⋅p(x3∣x1,x2)p(x_1, x_2, x_3) = p(x_1) \cdot p(x_2|x_1) \cdot p(x_3|x_1,x_2)p(x1​,x2​,x3​)=p(x1​)⋅p(x2​∣x1​)⋅p(x3​∣x1​,x2​)

MADE是一个神经网络，通过**掩码（mask）**切断某些连接，使得每个输出只依赖前面的输入，从而高效计算这个分解中的每个条件概率。

结构示意（简化版，实际隐藏层有更多节点和掩码连接）：

输入层          隐藏层           输出层
x₁ ──────────────────────────→ p(x₁=1) = y₁
x₂ ───────→ h₁ ──────────────→ p(x₂=1|x₁) = y₂  
x₃ ───────→ h₂ ──────────────→ p(x₃=1|x₁,x₂) = y₃

注：箭头仅表示信息流向。MADE 通过掩码矩阵强制 y₁ 只依赖 x₁，
y₂ 只依赖 x₁,x₂，以此类推。实际网络中所有输入连接所有隐藏节点，
但掩码选择性地屏蔽了"未来"信息的传递。

为什么重要：

  1. 可以计算任意构型的精确概率 p(x)p(\mathbf{x})p(x)：只需一次前向传播
  2. 可以采样新构型：按 x1→x2→⋯→xNx_1 \to x_2 \to \cdots \to x_Nx1​→x2​→⋯→xN​ 的顺序依次采样
  3. 复杂度 O(N2)O(N^2)O(N2)，比穷举 O(2N)O(2^N)O(2N) 快得多

VAE（Variational Autoencoder，变分自编码器）

VAE学习一个潜在空间（latent space），把高维数据压缩到低维，再从低维恢复高维。

结构：

编码器: x → μ, σ → z ~ N(μ, σ²)     （压缩到潜在空间）
解码器: z → x'                          （从潜在空间重建）

与MADE的关键区别：

VAE MADE
能否计算 p(x)p(\mathbf{x})p(x) ❌ 只能算下界（ELBO） ✅ 精确计算
采样速度 快（一次前向传播） 慢（逐个生成，O(N)O(N)O(N) 步）
适合MC提议 ❌ ✅

Flow Matching（流匹配）

Flow Matching是归一化流（Normalizing Flow）的升级版，直接学习一个连续的向量场（ODE），将简单分布（如高斯噪声）变换为目标分布。

重要区分：Flow Matching是一个训练框架（定义"学什么"——向量场），而不是网络架构。用什么神经网络来表示这个向量场是独立的选择。Lee & Wang 2026选择了U-Net（卷积架构）来表示向量场，从而获得平移等变性。如果换成全连接MLP，FM仍然能工作，但跨尺寸泛化能力就会丢失。

归一化流 (NF) 扩散模型 (DM) Flow Matching (FM)
学习目标 可逆变换 去噪过程 向量场（ODE）
精确概率 ✅ ❌ ✅
采样速度 快（一步） 慢（多步迭代） 中等（几步ODE）
训练稳定性 ⚠️ 不稳定 ✅ 稳定 ✅ 稳定

p(x)p(\mathbf{x})p(x) 和精确概率的重要性

p(x)p(\mathbf{x})p(x) 是神经网络学到的概率分布——即神经网络认为构型 x\mathbf{x}x 出现的概率。

在MCMC中，当神经网络作为提议分布时，Metropolis准则需要计算：

A(x′∣x)=min⁡{1,π(x′)π(x)⋅p(x)p(x′)}A(\mathbf{x}'|\mathbf{x}) = \min\left\{1, \frac{\pi(\mathbf{x}')}{\pi(\mathbf{x})} \cdot \frac{p(\mathbf{x})}{p(\mathbf{x}')}\right\}A(x′∣x)=min{1,π(x)π(x′)​⋅p(x′)p(x)​}

其中 π(x)\pi(\mathbf{x})π(x) 是目标分布（Boltzmann分布），p(x)p(\mathbf{x})p(x) 是NN学到的分布。如果不知道 p(x)p(\mathbf{x})p(x) 的精确值，就无法计算接受概率。

3D Edwards-Anderson（EA）自旋玻璃模型

这是论文②③④⑤共同研究的物理系统，也是本文档中最重要的测试平台。

基本定义

H=−∑⟨i,j⟩Jij si sj,si∈{−1,+1}H = -\sum_{\langle i,j \rangle} J_{ij} \, s_i \, s_j, \quad s_i \in \{-1, +1\}H=−⟨i,j⟩∑​Jij​si​sj​,si​∈{−1,+1}
  • 3D：自旋排列在三维立方晶格上，L×L×LL \times L \times LL×L×L，每个格点一个自旋
  • Edwards-Anderson：耦合常数 JijJ_{ij}Jij​ 是随机的（quenched disorder），不是均匀的
  • 自旋玻璃：由于随机耦合导致的几何挫折（frustration）

自旋类型：Ising自旋 si=±1s_i = \pm 1si​=±1（离散！）

这是与2D XY模型的根本区别：

Ising自旋（EA自旋玻璃） XY自旋（2D XY模型）
变量 si∈{−1,+1}s_i \in \{-1, +1\}si​∈{−1,+1} θi∈[0,2π)\theta_i \in [0, 2\pi)θi​∈[0,2π)
类型 离散（只有两个值） 连续（无穷多个值）
类比 硬币：只有正面/反面 指南针：可指向任何方向
自由度 每个格点1 bit 每个格点1个实数
生成模型适配 MADE（输出Bernoulli概率） FM（输出连续角度）

为什么EA用离散自旋而XY用连续角度？

  • Ising模型（s=±1s = \pm 1s=±1）：最简单的磁性模型，自旋只能"上"或"下"
  • XY模型（θ∈[0,2π)\theta \in [0, 2\pi)θ∈[0,2π)）：自旋可以在2D平面内指向任何方向，有更丰富的拓扑缺陷（涡旋）

几何挫折（Frustration）

考虑一个正方形上的4个自旋，耦合为 J12=+1,J23=+1,J34=+1,J41=−1J_{12} = +1, J_{23} = +1, J_{34} = +1, J_{41} = -1J12​=+1,J23​=+1,J34​=+1,J41​=−1：

s₁ ──(+)── s₂
|            |
(-)         (+)
|            |
s₄ ──(+)── s₃

要同时满足所有耦合是不可能的：

  • J12=+1J_{12}=+1J12​=+1：s₁和s₂要平行
  • J23=+1J_{23}=+1J23​=+1：s₂和s₃要平行
  • J34=+1J_{34}=+1J34​=+1：s₃和s₄要平行
  • J41=−1J_{41}=-1J41​=−1：s₄和s₁要反平行

但 s₁∥s₂∥s₃∥s₄ 意味着 s₁∥s₄，与 J41=−1J_{41}=-1J41​=−1 矛盾！

→ 几何挫折：不可能同时满足所有约束 → 基态简并 → 指数多个近简并低能态

3D EA的困难性

性质 说明
能量景观 极其复杂，指数多个近简并的局部极小
基态寻找 NP-hard（Barahona 1982）
低温Boltzmann采样 传统MC热化极慢（critical slowing down）
模式数量 指数多个模式 → 生成模型极易mode collapse
对称性 耦合JijJ_{ij}Jij​随机 → 平移对称性被破坏（与2D XY不同！）

平移对称性被破坏的含义：虽然晶格结构是周期性的（格点排列平移不变），但耦合值 JijJ_{ij}Jij​ 在每个位置不同。因此物理关联模式不是处处相同的，U-Net的平移等变性优势被削弱。

最大割问题（Max-Cut）与Ising基态

最大割问题：给定图 G=(V,E)G=(V,E)G=(V,E)，把顶点集分成两部分 SSS 和 Sˉ\bar{S}Sˉ，使横跨两部分的边权之和最大。

割边定义：一条边的两个端点分属不同集合时才是割边。同一侧的边不算。

与Ising基态的等价性：找Ising自旋玻璃的基态能量等价于求解最大割问题。Barahona (1982) 证明3D Ising自旋玻璃的基态寻找是NP-hard的。

3D EA自旋玻璃的基态

  • 构型空间是有限集 {−1,+1}N\{-1,+1\}^N{−1,+1}N，基态一定存在（有限集上的最小值）
  • 但NP-hard意味着大系统（N>1000N > 1000N>1000）无法在合理时间内精确求解
  • 论文中用BIQMAC求解器（branch-and-bound算法）对小系统求精确基态作为基准

NN的两种用法

用法A：NN作为MCMC提议分布（需要精确概率）

每一步MCMC:
    x' ← 从NN采样
    计算 A = min{1, [π(x')/π(x)] × [p(x)/p(x')]}  ← 需要p(x)！
    以概率A接受x'

用法B：NN生成初始构型 + 短链MCMC修正（不需要精确概率！）

步骤1: x₀ ← 从NN采样（不需要知道p(x₀)）
步骤2: 从x₀出发，跑短链传统MCMC

Mode Collapse（模式坍缩）

当目标分布有多个模式（"谷"）时，神经网络可能只学会其中一部分：

真实分布:  谷1(30%) 谷2(25%) 谷3(20%) 谷4(15%) 谷5(10%)
NN学到:    谷1(90%) 谷2(10%) 谷3(0%)  谷4(0%)  谷5(0%)

后果：NN只会提议谷1和谷2的构型，其余构型永远不会被提议，导致采样分布有偏。

论文①：Lu 2021 — NiMC

文件：01_Lu_2021_NiMC.pdf
标题：Network-Initialized Monte Carlo Based on Generative Neural Networks
作者：Hongyu Lu et al.（香港大学/中科院）
时间：2021年（arXiv），2022年5月更新

做了什么

用**VAE（变分自编码器）**生成接近平衡态的初始构型，从这些构型出发只需很短的MC链即可开始测量，跳过传统MC漫长的热化过程。

核心方法 

训练阶段:
    1. 用传统MC在目标温度T采样大量平衡构型
    2. 用这些构型训练VAE:
       - 编码器: x → z（压缩到潜在空间）
       - 解码器: z → x'（从潜在空间重建构型）
    3. VAE学会了目标温度下Boltzmann分布的近似

采样阶段:
    1. 从潜在空间随机采样 z ~ N(0, I)
    2. 用解码器生成构型 x₀ = Decoder(z)
    3. 从x₀出发，跑短链传统MC（几十步即可）
    4. 短MC链修正了VAE构型与真实平衡态的微小偏差
    5. 在修正后的构型上测量物理量

关键创新

创新1：完全消除自关联

  • VAE生成的每个构型是独立的（从不同的z采样）
  • 不像传统MC，连续构型之间有自关联
  • 短MC链（几十步）即可，而不是传统的数万步

创新2：适用于多种物理系统

  • 2D Ising模型（经典临界点）
  • 2D Hubbard模型（费米子Mott绝缘体、Dirac半金属、量子临界点）

测试系统

  1. 2D Ising模型：H=−J∑⟨i,j⟩sisjH = -J\sum_{\langle i,j\rangle} s_i s_jH=−J∑⟨i,j⟩​si​sj​，临界温度 Tc≈2.269JT_c \approx 2.269JTc​≈2.269J
  2. 2D Hubbard模型：费米子在格点上跃迁+在位排斥，用DQMC（行列式量子MC）框架

结果

  1. VAE生成的构型已非常接近平衡态，短MC链（几十步）即可修正
  2. 物理量（磁化强度、能量、关联函数等）的测量结果与长时间传统MC一致
  3. 自关联时间大幅缩短，等价于有效加速了采样

局限性

  • VAE不能计算精确概率 p(x)p(\mathbf{x})p(x)，所以不能用作MCMC提议分布
  • 只在简单系统（2D Ising, 2D Hubbard）上测试，未测试困难系统（如3D自旋玻璃）
  • 每个温度/参数需要单独训练VAE
  • 每个系统尺寸需要单独训练

论文②：Ciarella 2023 — ML-MC-fails

文件：02_Ciarella_2023_ML-MC-fails.pdf
标题：Machine-learning-assisted Monte Carlo fails at sampling computationally hard problems
作者：Ciarella, Trinquier, Weigt, Zamponi（巴黎文理研究大学/索邦大学）
时间：2023年
期刊：Machine Learning: Science and Technology

做了什么

证伪性研究：尝试用MADE（自回归神经网络）作为MCMC的提议分布来采样3D Edwards-Anderson自旋玻璃的Boltzmann分布，发现失败了。

核心方法 

方法1: 最大似然估计（MLE）训练MADE
    1. 先用传统MC在目标温度采样 → 得到训练数据
    2. 用这些数据训练MADE（最大化对数似然）
    3. 训练好的MADE作为MCMC的全局提议分布
    4. Metropolis准则:
       A = min{1, [π(x')/π(x)] × [p_MADE(x)/p_MADE(x')]}

方法2: 变分能量最小化训练MADE
    1. 不需要MC样本
    2. 直接最小化变分自由能 F_v = E_v - TS_v
    3. 其中 E_v = ⟨E(x)⟩_{p_MADE}, S_v = -⟨log p_MADE(x)⟩_{p_MADE}
    4. 训练好的MADE同样作为MCMC提议分布

关键发现：失败的原因

原因1：Mode Collapse（模式坍缩）

  • 3D EA自旋玻璃的能量景观极复杂，有指数多个近简并的低能态
  • MADE的容量有限，只学会了其中一部分模式的分布
  • 许多低能构型永远不会被提议

原因2：训练数据质量差

  • 传统MC在低温下本身就热化不了（critical slowing down）
  • 训练数据本身就是有偏的
  • MADE学到的分布继承了训练数据的偏差

原因3：全局提议的局限

  • MADE每次改变所有N个自旋
  • 即使接受率很低，一次成功的全局跳跃也不足以覆盖所有模式

测试系统

3D Edwards-Anderson自旋玻璃：

  • H=−∑⟨i,j⟩JijsisjH = -\sum_{\langle i,j\rangle} J_{ij} s_i s_jH=−∑⟨i,j⟩​Jij​si​sj​
  • 耦合 Jij∈{+1,−1}J_{ij} \in \{+1, -1\}Jij​∈{+1,−1} 随机（quenched disorder）
  • 严重的几何挫折

结果

  • 在小系统（L=4L=4L=4，64自旋）上，MADE勉强可用
  • 在中等系统（L=6∼8L=6\sim8L=6∼8）上，KL散度明显增大
  • 在大系统（L=10L=10L=10，1000自旋）上，MADE完全失败
  • 变分训练比MLE训练稍好，但仍然失败

局限性

  • 只测试了MADE一种网络架构
  • 没有尝试退火/逐步训练等策略
  • 没有结合局部和全局移动

重要意义

这篇论文不是负面结果，而是指出了一个重要问题：直接用生成模型替代传统MC提议在困难系统上是行不通的。这直接激励了后来的Del Bono 2026（在退火框架中逐步训练）和Nakano 2026（用量子电路提供优质训练数据）的工作。

论文③：Hunt-Smith 2023 — DM-MCMC

文件：03_Hunt-Smith_2023_DM-MCMC.pdf
标题：Accelerating Markov Chain Monte Carlo sampling with diffusion models
作者：N. T. Hunt-Smith et al.（阿德莱德大学、Jefferson Lab）
时间：2023年9月（arXiv预印本，投稿JHEP）

做了什么

用扩散模型（Diffusion Model）作为MCMC的全局提议分布，加速贝叶斯后验采样。与局部提议交替使用，并在MCMC运行过程中定期重训练扩散模型。

核心方法 

初始化:
    1. 从先验分布采样初始点
    2. 先跑一段传统MCMC（局部提议）收集初始样本

主循环:
    repeat:
        a. 局部提议阶段:
           for i = 1 to N_local:
               用传统Metropolis-Hastings（高斯随机游走）做局部更新
        
        b. 全局提议阶段:
           从扩散模型生成一个全局提议x'
           用Metropolis准则接受/拒绝（近似接受率）
        
        c. 定期重训练:
           每隔K步，用当前MCMC收集的样本重新训练扩散模型
           （DM越来越了解后验分布的形状）

关键创新

创新1：扩散模型作为全局提议

  • 扩散模型可以一次生成完整的参数向量（全局移动）
  • 与局部随机游走互补：局部移动精细探索，全局移动跨越模式

创新2：动态重训练

  • MCMC运行过程中，定期用当前样本重训练DM
  • DM从"完全不知道后验在哪"逐渐变成"很了解后验形状"
  • 越到后面，DM的全局提议质量越高

创新3：扩散模型适配低维连续数据

  • 标准DM是为图像（高维）设计的
  • 本文针对物理参数空间（~10维连续）做了定制

测试系统

  1. 解析测试函数：多峰高斯、Rosenbrock函数等
  2. 物理应用：部分子分布函数（PDF）的全局贝叶斯拟合
    • 从实验数据推断夸克/胶子在质子中的动量分布
    • 参数空间~10维，后验多峰

与其他论文的关键区别

区别点 说明
应用领域 高能物理（贝叶斯拟合），不是统计物理
数据类型 连续参数（~10维），不是离散自旋（N=1000+N=1000+N=1000+维）
精确概率 ❌ DM不能计算 p(x)p(\mathbf{x})p(x)，用近似接受率
训练方式 动态重训练，不是一次性训练

结果

  1. 显著减少了似然函数评估次数（比纯MCMC快数倍）
  2. 在多峰分布上有效跨越模式
  3. PDF拟合结果与传统MCMC一致

局限性

  • 接受率是近似的（DM不能给出精确 p(x)p(\mathbf{x})p(x)），引入了偏差
  • 只测试了低维（~10维）连续系统，未测试高维离散系统
  • 动态重训练的计算开销不可忽略
  • 系统规模远小于其他论文

三种退火方法

SA（Simulated Annealing，模拟退火） 

初始化: 随机构型 x, 高温 T_high
for T = T_high → T_low (共 θ 个温度):
    for step = 1 to θ_l = 15:
        随机选一个自旋 s_i → 翻转 → Metropolis接受/拒绝
    降温: T → T - ΔT
输出: 最终构型（希望是基态）
  • 纯局部移动：每次只翻转1个自旋
  • 1个SA = 1条独立的退火链
  • qqq 条SA = qqq 个独立退火链

PA（Population Annealing，种群退火） 

初始化: 生成 R₀ 个随机构型（种群），高温 T_high
for T = T_high → T_low:
    对种群中每个构型:
        for step = 1 to θ_l = 15:
            随机选一个自旋 → 翻转 → Metropolis接受/拒绝
    重采样: 根据Boltzmann权重复制/淘汰构型
    （高能量构型被淘汰，低能量构型被复制）
    种群大小保持 ~R₀
输出: 种群中能量最低的构型
  • 局部移动 + 种群重采样
  • 多个构型协同搜索
  • 重采样确保种群集中在低能区

GA（Generative Annealing，生成退火）★核心创新★ 

初始化: 生成 R₀ 个随机构型，高温 T_high
         初始化MADE（随机参数）
for T = T_high → T_low:
    ① 全局移动（MADE提议）:
       对种群中每个构型:
           从MADE采样新构型 x'
           Metropolis接受/拒绝
           如果接受 → 用x'替换当前构型
       用当前种群的构型训练MADE（1个epoch）
    
    ② 局部移动（单自旋翻转）:
       对种群中每个构型:
           for step = 1 to θ_l = 15:

  • HCH_CHC​ 是目标哈密顿量（Ising模型的能量函数）
  • HBH_BHB​ 是混合哈密顿量
  • γk,βk\gamma_k, \beta_kγk​,βk​ 是可调参数
  • 测量结果是一个自旋构型，天然偏向低能态

做了什么

用Flow Matching（流匹配）实现两个功能：

  1. 快速定位相变点（"小训练，大预测"）
  2. 为大系统生成高质量初始构型（跳过漫长热化）

核心方法 

训练阶段:
    在小系统（32×32）上，用传统MC在几个温度采样
    训练一个Flow Matching模型：
    - 输入: 温度T + 噪声
    - 输出: 该温度下的自旋构型
    - FM学习从噪声到Boltzmann分布的连续变换（向量场）

应用阶段:
    ① 定位相变点:
        把训练好的模型直接用于大系统（128×128）
        生成不同温度的构型 → 计算物理量 → 找到相变温度
        （不需要重新训练！）
    
    ② 生成初始构型:
        用FM在大系统的目标温度生成构型
        这些构型已经接近平衡态
        从这些构型出发，只需很短的MC链即可测量

创新1：跨温度泛化

  • 训练时只在几个温度（如 T=0.5,1.0,1.5,2.0T=0.5, 1.0, 1.5, 2.0T=0.5,1.0,1.5,2.0）有数据
  • 训练好的模型可以生成任意温度的构型（包括训练时没见过的温度）
  • 原理：FM学习的是温度条件下的连续向量场，可以插值

创新2：跨系统尺寸泛化（最亮眼！）

  • 在 32×3232\times3232×32（1024自旋）上训练
  • 直接用于 128×128128\times128128×128（16384自旋）
  • 不需要重新训练！

为什么可以跨尺寸？

  • 使用U-Net架构，基于卷积层，天然具有平移等变性（Translation Equivariance）
  • 平移等变性意味着：输入平移多少，输出就平移多少；卷积核在每个位置用同一组权重
  • 晶格物理系统具有平移对称性：每个格点上的哈密顿量形式完全相同
  • 因此模型在32×32上学到的局域关联（如近邻自旋关联）在128×128的每个位置都同样适用
  • 小系统学到的局域关联模式在大系统中同样适用
  • 就像学会了识别一小块拼图的模式，就能拼出大拼图

"物理直觉"的含义：因为物理是局域的且平移不变的，所以故意选择尊重这个对称性的网络架构（卷积/U-Net），而不是全连接网络（每个位置学不同的权重，会破坏平移对称性）。这个设计选择是跨尺寸泛化成立的关键前提。

为什么 U-Net 预测速度/噪声（而非自旋构型），平移等变性仍然重要？

U-Net 学习的是向量场 v(x,t,T)v(\mathbf{x}, t, T)v(x,t,T)，即 ODE dxdt=v(x,t,T)\frac{d\mathbf{x}}{dt} = v(\mathbf{x}, t, T)dtdx​=v(x,t,T) 中的速度。虽然预测的不是自旋构型本身，但速度场继承了目标分布的对称性：

物理哈密顿量平移不变 → 目标分布 p(x|T) 平移不变
→ 最优 ODE 路径在每个中间时刻 t 都平移等变
→ v*(平移(x), t, T) = 平移(v*(x, t, T))
→ U-Net（卷积）天然满足此性质 → 正确的归纳偏置
ODE 时刻 t x(t)\mathbf{x}(t)x(t) 的状态 速度场的含义 平移等变性
t=0t=0t=0 纯噪声（iid） "噪声往哪个方向走" ✅ 噪声每个位置独立同分布
t=0.5t=0.5t=0.5 噪声+构型的混合体 "继续向目标走" ✅ 中间分布仍平移不变

核心：起始分布（高斯噪声）和终止分布（Boltzmann分布）都平移不变 → 连接它们的条件向量场必然平移等变 → 卷积架构是正确的参数化方式 → 32×32 学到的卷积核在 128×128 同样适用。

延伸讨论

Q1：Flow Matching 能否迁移到退火框架（如 Del Bono 2026 的 GA）？

原则上可以，但面临三大障碍。

如果用 FM 替换 GA 中的 MADE：

方面 MADE（当前） FM（替换） 评估
精确概率 p(x)p(\mathbf{x})p(x) ✅ ✅ 无问题
训练速度 1 epoch/温度 需~10-50 epoch/温度 ❌ FM训练更慢
数据需求 少量种群即可 需要更多数据 ❌ 种群可能不够
数据类型 离散 ±1\pm1±1（Bernoulli） 连续（需额外处理） ❌ 最大障碍
采样速度 慢（逐自旋生成） 中等（解ODE） ✅
平移等变性 全连接，无 U-Net 卷积 ⚠️ 3D EA 耦合随机

核心障碍：

  1. 离散性：3D EA 自旋玻璃的自旋 ±1\pm1±1 是离散的，FM 天然处理连续空间。需要连续松弛等技巧，引入近似误差。
  2. 训练开销：MADE 只需 1 epoch/温度，FM 可能需要几十个 epoch。退火有数百个温度步 → 总训练时间可能不可接受。
  3. 3D EA 的平移对称性不完全：耦合 JijJ_{ij}Jij​ 是随机的 → 哈密顿量不完全平移不变。U-Net 的平移等变性优势被削弱。

但如果换到连续系统（如 2D XY）+ 退火 → FM + GA 的组合会很自然：FM 天然处理连续角度，U-Net 平移等变性被充分利用。

  ✅ 连续自旋 → FM 天然适配（直接输出角度速度场）
  ✅ 阻挫 → 需要全局移动（GA 的优势）
  ✅ 晶格结构 → U-Net 平移等变性可用（但不如无阻挫系统完美）
  ✅ 训练稳定 → FM 的 MSE 损失
  ✅ 精确概率 → FM 可计算，支持 Metropolis 准则

Q1.2.5：几何阻挫 vs 随机阻挫——平移对称性的关键区别

极其重要的观察：阻挫的来源决定了平移对称性是否被破坏。

自旋玻璃（EA/SK） 三角格反铁磁体 Kagome反铁磁体
阻挫来源 随机耦合 JijJ_{ij}Jij​ 三角形几何 Kagome几何
耦合是否均匀 ❌ 每条边不同 ✅ 处处相同 ✅ 处处相同
平移对称性 ❌ 被破坏 ✅ 完整保留 ✅ 完整保留
U-Net适用性 ⚠️ 削弱 ✅ 完美 ✅ 完美

为什么三角格/Kagome保留平移对称性？

以三角格反铁磁XY模型为例：

H=J∑⟨i,j⟩cos⁡(θi−θj),J>0H = J\sum_{\langle i,j \rangle} \cos(\theta_i - \theta_j), \quad J > 0H=J⟨i,j⟩∑​cos(θi​−θj​),J>0
  • 耦合 JJJ 处处相同（没有随机性）
  • 阻挫来自三角形的几何：三个自旋两两反铁磁耦合，无法同时满足所有边
  • 哈密顿量在晶格平移下完全不变
  • → U-Net 的平移等变性被完全利用！
三角格上的阻挫（反铁磁 J > 0）:
    θ₁ ─── θ₂
     \   /
      θ₃
    
    J > 0: 相邻自旋要反平行
    θ₁ ≠ θ₂, θ₂ ≠ θ₃, θ₃ ≠ θ₁
    但 θ₁ ≠ θ₂ 且 θ₂ ≠ θ₃ → θ₁ ≈ θ₃ → 与 θ₃ ≠ θ₁ 矛盾！
    
    → 几何阻挫！但耦合处处相同 → 平移对称性完整

结论：三角格/Kagome XY反铁磁体是FMA的最优系统

三角格/Kagome XY反铁磁体:
  ✅ 连续自旋 → FM 天然适配
  ✅ 几何阻挫 → 物理上有意义且有趣（自旋液体、冰规则等）
  ✅ 平移对称性完整 → U-Net 的归纳偏置被完全利用
  ✅ 可跨尺寸泛化 → 小系统训练，大系统使用
  ✅ 训练稳定 → FM 的 MSE 损失
  ✅ 精确概率 → FM 可计算，支持 Metropolis 准则

关于 warm-start：相邻温度的 Boltzmann 分布相近 → 上一温度的 FM 模型参数是下一温度的良好初始化 → 收敛快。

Q1.3：FMA（Flow Matching Annealing）的完整流程设计

目标：将 Flow Matching 与退火框架结合，专为连续阻挫系统（如 XY 自旋玻璃）设计。

FMA 算法流程 

Flow Matching Annealing (FMA) — 针对 XY 自旋玻璃

初始化:
    生成 R₀ 个随机角度构型（θ_i ∈ [0, 2π)），高温 T_high
    初始化 FM 模型（U-Net，随机参数）

for T = T_high → T_low (共 θ 个温度):
    
    ① 全局移动（FM 提议）:
       对种群中每个构型:
           a. 采样噪声 ε ~ N(0, I)
           b. 解 ODE: dθ/dt = v_φ(θ, t, T), t: 0→1
              得到提议构型 θ'
           c. 计算精确概率:
              log p_FM(θ') = log p₀(ε) - ∫₀¹ tr(∂v_φ/∂θ) dt
              （用 Hutchinson 迹估计，需几次前向传播）
           d. Metropolis 接受率:
              A = min{1, [π(θ')/π(θ)] × [p_FM(θ)/p_FM(θ')]}
           e. 以概率 A 接受 → 用 θ' 替换当前构型
       
       用当前种群构型训练 FM（warm-start，K 个 epoch）
    
    ② 局部移动（角度微扰）:
       对种群中每个构型:
           for step = 1 to θ_l:
               随机选一个自旋 i
               角度微调: θ_i → θ_i + Δθ  (Δθ 从均匀分布采样)
               Metropolis 接受/拒绝
    
    ③ 重采样（与 PA/GA 相同）:
       根据 Boltzmann 权重复制/淘汰构型
       种群大小保持 ~R₀

输出: 种群中能量最低的构型（优化）或测量物理量（采样）

FMA 中 FM 的训练细节 

每温度的训练步骤（warm-start）:

输入: 当前种群的 R₀ 个构型 {θ⁽¹⁾, ..., θ⁽ᴿ⁾}（已标签"好"）
      上一温度的 FM 模型参数 φ_{T+ΔT}（warm-start）

for epoch = 1 to K:  (K = 1~5)
    for each 构型 θ⁽ⁱ⁾ in minibatch:
        1. 采样 t ~ U[0,1]
        2. 采样噪声 ε ~ N(0, I)
        3. 插值: θ_t = (1-t)·ε + t·θ⁽ⁱ⁾
        4. 计算目标速度: u = θ⁽ⁱ⁾ - ε
        5. 前向传播: v_φ(θ_t, t, T)
        6. 损失: L = ||v_φ - u||²
    更新 φ ← φ - η·∇L
    
输出: 更新后的 FM 模型参数 φ_T

FMA vs GA 对比

方面 GA（MADE + 退火） FMA（FM + 退火）
目标系统 离散（si=±1s_i = \pm 1si​=±1） 连续（θi∈[0,2π)\theta_i \in [0, 2\pi)θi​∈[0,2π)）
生成模型 MADE（全连接） FM（U-Net 卷积）
全局采样方式 自回归（逐自旋） 解 ODE（并行）
精确概率 ✅ 一次前向传播 ✅ Hutchinson 迹估计
每温度训练 1 epoch K = 1~5 epoch（warm-start）
平移等变性 ❌ 全连接无 ✅ U-Net 卷积
采样速度 慢（O(N)O(N)O(N) 步自回归） 中等（O(S)O(S)O(S) 步 ODE，S∼10S \sim 10S∼10~100）

FMA 的优势：为什么 FM 在退火框架中可能更高效

  1. 温度条件输入：FM 接收温度 TTT 作为输入 → 从 TTT 到 T−ΔTT-\Delta TT−ΔT 时，只需微调而非从头训练
  2. Warm-start：用 TTT 的模型初始化 T−ΔTT-\Delta TT−ΔT → 相邻温度的分布相似 → 收敛快
  3. 并行采样：ODE 求解可以批量并行（GPU），而 MADE 的自回归采样是严格串行的
  4. U-Net 的归纳偏置：即使随机耦合削弱了平移等变性，局域关联仍然有用

FMA 的剩余挑战

挑战 严重程度 可能的解决方案
训练开销 ⚠️ 主要问题 warm-start + 温度条件输入 → 可能只需1-3 epoch
精确概率计算开销 ⚠️ 中等 Hutchinson 迹估计需~10次前向传播；可用低阶近似
ODE 求解开销 ⚠️ 中等 自适应步长求解器；或用更少的 ODE 步数
随机耦合削弱平移等变性 ⚠️ 轻微 选择三角格/Kagome系统可完全避免（几何阻挫保留平移对称性）

结论：问题是否只剩训练开销？

不完全是。训练开销是主要问题，但还有两个次要问题：

  1. 精确概率的计算开销（Hutchinson 迹估计）——增加了每步 Metropolis 的成本
  2. ODE 采样开销——需要多步数值积分

但这些问题都有成熟的解决方案（低阶近似、自适应求解器等），且在连续系统中不存在根本性障碍。与 GA 在离散系统上面临的"离散性"这个根本障碍不同，FMA 在连续系统上面临的都是工程层面的优化问题。

Q1.5：FM 的神经网络本质上也在学习"去噪"，那它不就是另一种形式的 MADE 吗？

对，本质上都是"神经网络学习数据分布"，但关键差异在于输出空间。

MADE:  输入 x → 输出 p(s_i = +1 | s_{<i})  → Bernoulli 概率（离散）
FM:    输入 x_t, t → 输出 v(x_t, t)          → 连续速度（连续）

两者都是神经网络，都在学习数据分布的某种表示。但：

MADE FM
输出 每个自旋的 Bernoulli 概率 整个构型的连续速度场
天然适配 离散数据（±1\pm 1±1） 连续数据（角度、像素值）
处理离散的方式 直接（输出就是概率） 间接（需要连续松弛，再离散化）
在 GA 中替换 当前方案 需要额外处理离散性

所以本质上 FM 确实可以替代 MADE 的角色——都是"学习分布 + 提供提议"——但替换的难点不在于学习范式，而在于数据类型适配：FM 在连续空间很自然，但在离散空间需要额外的松弛技巧（如 Gumbel-Softmax、连续近似等），这会引入近似误差。

Q2：Flow Matching 需不需要 gradient-free 优化？

不需要。FM 用标准梯度下降（Adam）训练，损失函数是简单的 MSE。

FM 训练目标（Conditional Flow Matching）:
    L = E_{t, x₀, x₁} || v_θ(x_t, t) - (x₁ - x₀) ||²

    x₀ ~ N(0, I)           （噪声）
    x₁ ~ 训练数据           （真实构型）
    x_t = (1-t)·x₀ + t·x₁  （线性插值）
    v_θ = U-Net 输出         （预测速度）

    → 简单的回归问题，完全可微，Adam 即可优化
