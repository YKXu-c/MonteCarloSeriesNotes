## 核心概念解释

### MADE（Masked Autoencoder Distribution Estimator）

**MADE = 掩码自编码器分布估计器**

任何联合概率分布都可以分解为条件概率的乘积：

$$p(x_1, x_2, x_3) = p(x_1) \cdot p(x_2|x_1) \cdot p(x_3|x_1,x_2)$$

MADE是一个神经网络，通过**掩码（mask）**切断某些连接，使得每个输出只依赖前面的输入，从而高效计算这个分解中的每个条件概率。

**结构示意**（简化版，实际隐藏层有更多节点和掩码连接）：
```
输入层          隐藏层           输出层
x₁ ──────────────────────────→ p(x₁=1) = y₁
x₂ ───────→ h₁ ──────────────→ p(x₂=1|x₁) = y₂  
x₃ ───────→ h₂ ──────────────→ p(x₃=1|x₁,x₂) = y₃

注：箭头仅表示信息流向。MADE 通过掩码矩阵强制 y₁ 只依赖 x₁，
y₂ 只依赖 x₁,x₂，以此类推。实际网络中所有输入连接所有隐藏节点，
但掩码选择性地屏蔽了"未来"信息的传递。
```

**为什么重要**：
1. 可以计算任意构型的精确概率 $p(\mathbf{x})$：只需一次前向传播
2. 可以采样新构型：按 $x_1 \to x_2 \to \cdots \to x_N$ 的顺序依次采样
3. 复杂度 $O(N^2)$，比穷举 $O(2^N)$ 快得多

### VAE（Variational Autoencoder，变分自编码器）

VAE学习一个**潜在空间（latent space）**，把高维数据压缩到低维，再从低维恢复高维。

**结构**：
```
编码器: x → μ, σ → z ~ N(μ, σ²)     （压缩到潜在空间）
解码器: z → x'                          （从潜在空间重建）
```

**与MADE的关键区别**：

| | VAE | MADE |
|---|---|---|
| 能否计算 $p(\mathbf{x})$ | ❌ 只能算下界（ELBO） | ✅ 精确计算 |
| 采样速度 | 快（一次前向传播） | 慢（逐个生成，$O(N)$ 步） |
| 适合MC提议 | ❌ | ✅ |

### Flow Matching（流匹配）

Flow Matching是**归一化流（Normalizing Flow）的升级版**，直接学习一个连续的向量场（ODE），将简单分布（如高斯噪声）变换为目标分布。

> **重要区分**：Flow Matching是一个**训练框架**（定义"学什么"——向量场），而不是网络架构。用什么神经网络来表示这个向量场是**独立的选择**。Lee & Wang 2026选择了U-Net（卷积架构）来表示向量场，从而获得平移等变性。如果换成全连接MLP，FM仍然能工作，但跨尺寸泛化能力就会丢失。

| | 归一化流 (NF) | 扩散模型 (DM) | Flow Matching (FM) |
|---|---|---|---|
| 学习目标 | 可逆变换 | 去噪过程 | 向量场（ODE） |
| 精确概率 | ✅ | ❌ | ✅ |
| 采样速度 | 快（一步） | 慢（多步迭代） | 中等（几步ODE） |
| 训练稳定性 | ⚠️ 不稳定 | ✅ 稳定 | ✅ 稳定 |

### $p(\mathbf{x})$ 和精确概率的重要性

$p(\mathbf{x})$ 是神经网络学到的概率分布——即神经网络认为构型 $\mathbf{x}$ 出现的概率。

在MCMC中，当神经网络作为**提议分布**时，Metropolis准则需要计算：

$$A(\mathbf{x}'|\mathbf{x}) = \min\left\{1, \frac{\pi(\mathbf{x}')}{\pi(\mathbf{x})} \cdot \frac{p(\mathbf{x})}{p(\mathbf{x}')}\right\}$$

其中 $\pi(\mathbf{x})$ 是目标分布（Boltzmann分布），$p(\mathbf{x})$ 是NN学到的分布。**如果不知道 $p(\mathbf{x})$ 的精确值，就无法计算接受概率。**

### 3D Edwards-Anderson（EA）自旋玻璃模型

**这是论文②③④⑤共同研究的物理系统，也是本文档中最重要的测试平台。**

#### 基本定义

$$H = -\sum_{\langle i,j \rangle} J_{ij} \, s_i \, s_j, \quad s_i \in \{-1, +1\}$$

- **3D**：自旋排列在三维立方晶格上，$L \times L \times L$，每个格点一个自旋
- **Edwards-Anderson**：耦合常数 $J_{ij}$ 是**随机**的（quenched disorder），不是均匀的
- **自旋玻璃**：由于随机耦合导致的**几何挫折**（frustration）

#### 自旋类型：Ising自旋 $s_i = \pm 1$（离散！）

这是与2D XY模型的**根本区别**：

| | Ising自旋（EA自旋玻璃） | XY自旋（2D XY模型） |
|---|---|---|
| 变量 | $s_i \in \{-1, +1\}$ | $\theta_i \in [0, 2\pi)$ |
| 类型 | **离散**（只有两个值） | **连续**（无穷多个值） |
| 类比 | 硬币：只有正面/反面 | 指南针：可指向任何方向 |
| 自由度 | 每个格点1 bit | 每个格点1个实数 |
| 生成模型适配 | MADE（输出Bernoulli概率） | FM（输出连续角度） |

**为什么EA用离散自旋而XY用连续角度？**
- Ising模型（$s = \pm 1$）：最简单的磁性模型，自旋只能"上"或"下"
- XY模型（$\theta \in [0, 2\pi)$）：自旋可以在2D平面内指向任何方向，有更丰富的拓扑缺陷（涡旋）

#### 几何挫折（Frustration）

考虑一个正方形上的4个自旋，耦合为 $J_{12} = +1, J_{23} = +1, J_{34} = +1, J_{41} = -1$：

```
s₁ ──(+)── s₂
|            |
(-)         (+)
|            |
s₄ ──(+)── s₃
```

要同时满足所有耦合是不可能的：
- $J_{12}=+1$：s₁和s₂要平行
- $J_{23}=+1$：s₂和s₃要平行
- $J_{34}=+1$：s₃和s₄要平行
- $J_{41}=-1$：s₄和s₁要**反平行**

但 s₁∥s₂∥s₃∥s₄ 意味着 s₁∥s₄，与 $J_{41}=-1$ 矛盾！

→ **几何挫折**：不可能同时满足所有约束 → 基态简并 → 指数多个近简并低能态

#### 3D EA的困难性

| 性质 | 说明 |
|------|------|
| 能量景观 | 极其复杂，指数多个近简并的局部极小 |
| 基态寻找 | NP-hard（Barahona 1982） |
| 低温Boltzmann采样 | 传统MC热化极慢（critical slowing down） |
| 模式数量 | 指数多个模式 → 生成模型极易mode collapse |
| 对称性 | 耦合$J_{ij}$随机 → **平移对称性被破坏**（与2D XY不同！） |

**平移对称性被破坏的含义**：虽然晶格结构是周期性的（格点排列平移不变），但耦合值 $J_{ij}$ 在每个位置不同。因此物理关联模式不是处处相同的，U-Net的平移等变性优势被削弱。

### 最大割问题（Max-Cut）与Ising基态

**最大割问题**：给定图 $G=(V,E)$，把顶点集分成两部分 $S$ 和 $\bar{S}$，使横跨两部分的边权之和最大。

**割边定义**：一条边的两个端点**分属不同集合**时才是割边。同一侧的边不算。

**与Ising基态的等价性**：找Ising自旋玻璃的基态能量等价于求解最大割问题。Barahona (1982) 证明3D Ising自旋玻璃的基态寻找是**NP-hard**的。

### 3D EA自旋玻璃的基态

- 构型空间是有限集 $\{-1,+1\}^N$，基态**一定存在**（有限集上的最小值）
- 但NP-hard意味着大系统（$N > 1000$）无法在合理时间内精确求解
- 论文中用BIQMAC求解器（branch-and-bound算法）对小系统求精确基态作为**基准**

### NN的两种用法

**用法A：NN作为MCMC提议分布（需要精确概率）**
```
每一步MCMC:
    x' ← 从NN采样
    计算 A = min{1, [π(x')/π(x)] × [p(x)/p(x')]}  ← 需要p(x)！
    以概率A接受x'
```

**用法B：NN生成初始构型 + 短链MCMC修正（不需要精确概率！）**
```
步骤1: x₀ ← 从NN采样（不需要知道p(x₀)）
步骤2: 从x₀出发，跑短链传统MCMC
```

### Mode Collapse（模式坍缩）

当目标分布有多个模式（"谷"）时，神经网络可能只学会其中一部分：

```
真实分布:  谷1(30%) 谷2(25%) 谷3(20%) 谷4(15%) 谷5(10%)
NN学到:    谷1(90%) 谷2(10%) 谷3(0%)  谷4(0%)  谷5(0%)
```

后果：NN只会提议谷1和谷2的构型，其余构型永远不会被提议，导致采样分布有偏。

## 论文①：Lu 2021 — NiMC

**文件**：`01_Lu_2021_NiMC.pdf`
**标题**：Network-Initialized Monte Carlo Based on Generative Neural Networks
**作者**：Hongyu Lu et al.（香港大学/中科院）
**时间**：2021年（arXiv），2022年5月更新

### 做了什么

用**VAE（变分自编码器）**生成接近平衡态的初始构型，从这些构型出发只需很短的MC链即可开始测量，**跳过传统MC漫长的热化过程**。

### 核心方法

```
训练阶段:
    1. 用传统MC在目标温度T采样大量平衡构型
    2. 用这些构型训练VAE:
       - 编码器: x → z（压缩到潜在空间）
       - 解码器: z → x'（从潜在空间重建构型）
    3. VAE学会了目标温度下Boltzmann分布的近似

采样阶段:
    1. 从潜在空间随机采样 z ~ N(0, I)
    2. 用解码器生成构型 x₀ = Decoder(z)
    3. 从x₀出发，跑短链传统MC（几十步即可）
    4. 短MC链修正了VAE构型与真实平衡态的微小偏差
    5. 在修正后的构型上测量物理量
```

### 关键创新

**创新1：完全消除自关联**
- VAE生成的每个构型是独立的（从不同的z采样）
- 不像传统MC，连续构型之间有自关联
- 短MC链（~几十步）即可，而不是传统的~数万步

**创新2：适用于多种物理系统**
- 2D Ising模型（经典临界点）
- 2D Hubbard模型（费米子Mott绝缘体、Dirac半金属、量子临界点）

### 测试系统

1. **2D Ising模型**：$H = -J\sum_{\langle i,j\rangle} s_i s_j$，临界温度 $T_c \approx 2.269J$
2. **2D Hubbard模型**：费米子在格点上跃迁+在位排斥，用DQMC（行列式量子MC）框架

### 结果

1. VAE生成的构型已非常接近平衡态，短MC链（几十步）即可修正
2. 物理量（磁化强度、能量、关联函数等）的测量结果与长时间传统MC一致
3. 自关联时间大幅缩短，等价于有效加速了采样

### 局限性

- VAE不能计算精确概率 $p(\mathbf{x})$，所以**不能用作MCMC提议分布**
- 只在简单系统（2D Ising, 2D Hubbard）上测试，未测试困难系统（如3D自旋玻璃）
- 每个温度/参数需要单独训练VAE
- 每个系统尺寸需要单独训练

## 论文②：Ciarella 2023 — ML-MC-fails

**文件**：`02_Ciarella_2023_ML-MC-fails.pdf`
**标题**：Machine-learning-assisted Monte Carlo fails at sampling computationally hard problems
**作者**：Ciarella, Trinquier, Weigt, Zamponi（巴黎文理研究大学/索邦大学）
**时间**：2023年
**期刊**：Machine Learning: Science and Technology

### 做了什么

**证伪性研究**：尝试用MADE（自回归神经网络）作为MCMC的提议分布来采样3D Edwards-Anderson自旋玻璃的Boltzmann分布，**发现失败了**。

### 核心方法

```
方法1: 最大似然估计（MLE）训练MADE
    1. 先用传统MC在目标温度采样 → 得到训练数据
    2. 用这些数据训练MADE（最大化对数似然）
    3. 训练好的MADE作为MCMC的全局提议分布
    4. Metropolis准则:
       A = min{1, [π(x')/π(x)] × [p_MADE(x)/p_MADE(x')]}

方法2: 变分能量最小化训练MADE
    1. 不需要MC样本
    2. 直接最小化变分自由能 F_v = E_v - TS_v
    3. 其中 E_v = ⟨E(x)⟩_{p_MADE}, S_v = -⟨log p_MADE(x)⟩_{p_MADE}
    4. 训练好的MADE同样作为MCMC提议分布
```

### 关键发现：失败的原因

**原因1：Mode Collapse（模式坍缩）**
- 3D EA自旋玻璃的能量景观极复杂，有指数多个近简并的低能态
- MADE的容量有限，只学会了其中一部分模式的分布
- 许多低能构型永远不会被提议

**原因2：训练数据质量差**
- 传统MC在低温下本身就热化不了（critical slowing down）
- 训练数据本身就是有偏的
- MADE学到的分布继承了训练数据的偏差

**原因3：全局提议的局限**
- MADE每次改变所有N个自旋
- 即使接受率很低，一次成功的全局跳跃也不足以覆盖所有模式

### 测试系统

**3D Edwards-Anderson自旋玻璃**：
- $H = -\sum_{\langle i,j\rangle} J_{ij} s_i s_j$
- 耦合 $J_{ij} \in \{+1, -1\}$ 随机（quenched disorder）
- 严重的几何挫折

### 结果

- 在小系统（$L=4$，64自旋）上，MADE勉强可用
- 在中等系统（$L=6\sim8$）上，KL散度明显增大
- 在大系统（$L=10$，1000自旋）上，**MADE完全失败**
- 变分训练比MLE训练稍好，但仍然失败

### 局限性

- 只测试了MADE一种网络架构
- 没有尝试退火/逐步训练等策略
- 没有结合局部和全局移动

### 重要意义

这篇论文**不是负面结果**，而是指出了一个重要问题：**直接用生成模型替代传统MC提议在困难系统上是行不通的**。这直接激励了后来的Del Bono 2026（在退火框架中逐步训练）和Nakano 2026（用量子电路提供优质训练数据）的工作。

## 论文③：Hunt-Smith 2023 — DM-MCMC

**文件**：`03_Hunt-Smith_2023_DM-MCMC.pdf`
**标题**：Accelerating Markov Chain Monte Carlo sampling with diffusion models
**作者**：N. T. Hunt-Smith et al.（阿德莱德大学、Jefferson Lab）
**时间**：2023年9月（arXiv预印本，投稿JHEP）

### 做了什么

用**扩散模型（Diffusion Model）**作为MCMC的全局提议分布，加速**贝叶斯后验采样**。与局部提议交替使用，并在MCMC运行过程中**定期重训练**扩散模型。

### 核心方法

```
初始化:
    1. 从先验分布采样初始点
    2. 先跑一段传统MCMC（局部提议）收集初始样本

主循环:
    repeat:
        a. 局部提议阶段:
           for i = 1 to N_local:
               用传统Metropolis-Hastings（高斯随机游走）做局部更新
        
        b. 全局提议阶段:
           从扩散模型生成一个全局提议x'
           用Metropolis准则接受/拒绝（近似接受率）
        
        c. 定期重训练:
           每隔K步，用当前MCMC收集的样本重新训练扩散模型
           （DM越来越了解后验分布的形状）
```

### 关键创新

**创新1：扩散模型作为全局提议**
- 扩散模型可以一次生成完整的参数向量（全局移动）
- 与局部随机游走互补：局部移动精细探索，全局移动跨越模式

**创新2：动态重训练**
- MCMC运行过程中，定期用当前样本重训练DM
- DM从"完全不知道后验在哪"逐渐变成"很了解后验形状"
- 越到后面，DM的全局提议质量越高

**创新3：扩散模型适配低维连续数据**
- 标准DM是为图像（高维）设计的
- 本文针对物理参数空间（~10维连续）做了定制

### 测试系统

1. **解析测试函数**：多峰高斯、Rosenbrock函数等
2. **物理应用**：部分子分布函数（PDF）的全局贝叶斯拟合
   - 从实验数据推断夸克/胶子在质子中的动量分布
   - 参数空间~10维，后验多峰

### 与其他论文的关键区别

| 区别点 | 说明 |
|--------|------|
| **应用领域** | 高能物理（贝叶斯拟合），不是统计物理 |
| **数据类型** | 连续参数（~10维），不是离散自旋（$N=1000+$维） |
| **精确概率** | ❌ DM不能计算 $p(\mathbf{x})$，用近似接受率 |
| **训练方式** | 动态重训练，不是一次性训练 |

### 结果

1. 显著减少了似然函数评估次数（比纯MCMC快数倍）
2. 在多峰分布上有效跨越模式
3. PDF拟合结果与传统MCMC一致

### 局限性

- **接受率是近似的**（DM不能给出精确 $p(\mathbf{x})$），引入了偏差
- 只测试了低维（~10维）连续系统，未测试高维离散系统
- 动态重训练的计算开销不可忽略
- 系统规模远小于其他论文

## 论文④：Del Bono 2026 — GA/PA/SA

**文件**：`04_Del-Bono_2026_GA-PA-SA.pdf`
**标题**：Demonstrating real advantage of machine-learning-enhanced Monte Carlo for combinatorial optimization
**作者**：Del Bono, Ricci-Tersenghi, Zamponi（罗马大学/索邦大学）
**时间**：2026年（PNAS）
**注**：这是Ciarella 2023同一团队的后续工作

### 做了什么

系统比较了三种退火方法（SA、PA、GA）在3D EA自旋玻璃优化上的表现，**首次用严格的时间对比证明了ML增强MC（GA）的真正优势**。

### 三种退火方法

#### SA（Simulated Annealing，模拟退火）

```
初始化: 随机构型 x, 高温 T_high
for T = T_high → T_low (共 θ 个温度):
    for step = 1 to θ_l = 15:
        随机选一个自旋 s_i → 翻转 → Metropolis接受/拒绝
    降温: T → T - ΔT
输出: 最终构型（希望是基态）
```

- **纯局部移动**：每次只翻转1个自旋
- 1个SA = 1条独立的退火链
- $q$ 条SA = $q$ 个独立退火链

#### PA（Population Annealing，种群退火）

```
初始化: 生成 R₀ 个随机构型（种群），高温 T_high
for T = T_high → T_low:
    对种群中每个构型:
        for step = 1 to θ_l = 15:
            随机选一个自旋 → 翻转 → Metropolis接受/拒绝
    重采样: 根据Boltzmann权重复制/淘汰构型
    （高能量构型被淘汰，低能量构型被复制）
    种群大小保持 ~R₀
输出: 种群中能量最低的构型
```

- **局部移动 + 种群重采样**
- 多个构型协同搜索
- 重采样确保种群集中在低能区

#### GA（Generative Annealing，生成退火）★核心创新★

```
初始化: 生成 R₀ 个随机构型，高温 T_high
         初始化MADE（随机参数）
for T = T_high → T_low:
    ① 全局移动（MADE提议）:
       对种群中每个构型:
           从MADE采样新构型 x'
           Metropolis接受/拒绝
           如果接受 → 用x'替换当前构型
       用当前种群的构型训练MADE（1个epoch）
    
    ② 局部移动（单自旋翻转）:
       对种群中每个构型:
           for step = 1 to θ_l = 15:
               随机选一个自旋 → 翻转 → Metropolis接受/拒绝
    
    ③ 重采样（与PA相同）
输出: 种群中能量最低的构型
```

### GA的关键设计细节

**训练数据**：当前温度的PA种群构型
- 种群经过局部移动和重采样后，已经集中在低能区
- 这些低能构型作为MADE的训练数据
- MADE学会了当前温度的低能构型分布

**训练频率**：每个温度1个epoch
- 不需要大量训练（训练数据已经在正确区域）
- 1个epoch足够MADE学到有用的模式

**局部修正**（$\theta_l = 15$ MCS）：
- MADE的全局提议不精确（大致指向低能区但不精确）
- 15步单自旋翻转微调构型到附近的局部极小值
- 类比：飞机到上海（全局）+ 打车到地址（局部）

**GA15的含义**：$\theta_l = 15$ MCS的局部修正步数

### 测试系统

**3D Edwards-Anderson自旋玻璃**：
- $H = -\sum_{\langle i,j\rangle} J_{ij} s_i s_j$，$J_{ij} \in \{+1, -1\}$
- $L = 10$（$N = 1000$自旋）和 $L = 14$（$N = 2744$自旋）
- 精确基态用BIQMAC求解器（branch-and-bound算法）获得

### 公平时间对比的关键

$$T_{\text{total}} = q \times \theta \times \theta_l \times N$$

- $q$：独立运行次数
- $\theta$：温度步数
- $\theta_l$：每个温度的MCS步数
- $N$：自旋数

**SA**：$q = 10000$（很多独立链），每条链 $\theta \times \theta_l \times N$ 步
**PA**：$q = 1$，但种群 $R_0 = 10000$，等价于10000条链
**GA**：$q = 1$，种群 $R_0 = 10000$，但每步多了MADE训练和全局移动时间

### 结果

1. **小系统（$L=10$）**：GA找到精确基态的成功率显著高于SA和PA
2. **大系统（$L=14$）**：GA的优势更明显——SA几乎找不到基态，GA成功率保持
3. **低温平衡态验证**：GA在 $T=0.1$ 时的构型分布与长时间PA结果一致，确认无偏

### 如何解决Ciarella 2023的问题

| Ciarella的问题 | Del Bono的解决方案 |
|---|---|
| 训练数据质量差 | PA种群提供高质量训练数据 |
| 一次性训练不够 | 每温度重训练（逐步适应） |
| mode collapse | 种群本身就覆盖多个模式 |
| 无局部修正 | 15 MCS局部翻转弥补MADE不精确 |

### 局限性

- 训练时间不可忽略（GPU上每温度需要几秒训练MADE）
- 只在优化（找基态）上验证，未在采样（求物理量）上验证
- 低温下GA和PA的性能差距缩小

## 论文⑤：Nakano 2026 — QAOA-NN-MC

**文件**：`05_Nakano_2026_QAOA-NN-MC.pdf`
**标题**：Neural-Network-Assisted Monte Carlo Sampling Trained by QAOA
**作者**：Nakano, Okada, Fujii（大阪大学）
**时间**：2026年（PRX Quantum）

### 做了什么

用**量子计算机**（QAOA电路）生成高质量训练数据 → 训练经典神经网络（MADE）→ MADE作为MCMC的全局提议分布，实现比纯经典方法多项式加速的采样。

### 核心方法

```
步骤1: 量子数据生成
    在量子计算机上运行QAOA（Quantum Approximate Optimization Algorithm）
    QAOA天然倾向于低能态 → 采样的构型偏向低能量
    得到一批"量子增强"的训练数据

步骤2: 训练经典神经网络
    用QAOA采样数据训练MADE（40个epoch）
    MADE学会了量子增强的低能构型分布

步骤3: 经典MCMC采样
    MADE作为MCMC的全局提议分布
    Metropolis准则:
    A = min{1, [π(x')/π(x)] × [p_MADE(x)/p_MADE(x')]}
    接受/拒绝
```

### QAOA是什么？

QAOA（量子近似优化算法）是一种在量子计算机上运行的可编程量子电路：

```
|0⟩^⊗n → H^⊗n → exp(-iγ₁H_C) → exp(-iβ₁H_B) → ... → 测量
```

- $H_C$ 是目标哈密顿量（Ising模型的能量函数）
- $H_B$ 是混合哈密顿量
- $\gamma_k, \beta_k$ 是可调参数
- 测量结果是一个自旋构型，**天然偏向低能态**

### 关键创新

**创新1：量子-经典混合提议分布**

不把QAOA直接用于采样（量子比特有限），而是用QAOA训练经典NN：
- 量子计算机：生成 $O(n)$ 个高质量样本（受限于量子比特数）
- 经典NN：从这些样本学习后，可以处理任意大的系统

**创新2：固定角度QAOA也有效**

不需要优化QAOA参数，随机选的参数就能生成有用的训练数据：
- 大幅降低了量子计算的开销
- 实际上只需要"粗略指向低能区"就够了

**创新3：谱隙加速的理论分析**

证明了MADE辅助MCMC的谱隙（spectral gap）比纯MCMC大~$n^3$倍：
- 谱隙越大，MCMC收敛越快
- 意味着多项式加速（不是指数的，但显著）

### 混合提议分布的细节

$$T_{\text{hybrid}} = (1-\alpha) \cdot T_{\text{local}} + \alpha \cdot T_{\text{global}}$$

- $T_{\text{local}}$：单自旋翻转（传统MC）
- $T_{\text{global}}$：MADE全局提议
- $\alpha$：全局移动的概率（超参数）

每个MCMC步骤：
1. 以概率 $\alpha$：从MADE采样全局构型，Metropolis接受/拒绝
2. 以概率 $1-\alpha$：随机翻转一个自旋，Metropolis接受/拒绝

### 测试系统

**全连接SK模型（Sherrington-Kirkpatrick）**：
- $H = -\sum_{i<j} J_{ij} s_i s_j$，$J_{ij}$ 从高斯分布随机抽取
- 所有自旋两两耦合（不是近邻）
- $n = 3 \sim 25$（受限于量子模拟器）

### 结果

1. 比纯MCMC快~$n^3$倍（多项式加速）
2. 比其他经典训练方式（如从随机数据训练）明显更好
3. 即使QAOA参数未优化（固定角度），加速效果仍然显著
4. 低温下加速效果最明显（高温时传统MC已经足够快）

### 与其他论文的对比

| | Del Bono 2026 | Nakano 2026 |
|---|---|---|
| 训练数据来源 | PA种群（经典） | QAOA采样（量子） |
| 每温度重训练 | ✅ 是 | ❌ 否（一次训练） |
| 局部修正 | 15 MCS | 混合提议（概率$\alpha$） |
| 任务 | 优化 | 采样 |
| 自旋玻璃类型 | 3D EA（近邻耦合） | SK（全连接） |
| 理论分析 | 经验对比 | 谱隙理论证明 |

### 局限性

- 需要量子计算机（或量子模拟器）
- 系统规模受限于量子比特数（目前 $n \leq 25$）
- 高温时加速效果不明显
- 只测试了SK模型，未测试3D EA

## 论文⑥：Lee & Wang 2026 — FM-Critical

**文件**：`06_Lee-Wang_2026_FM-Critical.pdf`
**标题**：Efficient Identification of Critical Transitions via Flow Matching: A Scalable Generative Approach for Many-Body Systems
**作者**：Qian-Rui Lee, Daw-Wei Wang（国立清华大学，台湾）
**时间**：2026年1月（预印本）

### 做了什么

用**Flow Matching**（流匹配）实现两个功能：

1. **快速定位相变点**（"小训练，大预测"）
2. **为大系统生成高质量初始构型**（跳过漫长热化）

### 核心方法

```
训练阶段:
    在小系统（32×32）上，用传统MC在几个温度采样
    训练一个Flow Matching模型：
    - 输入: 温度T + 噪声
    - 输出: 该温度下的自旋构型
    - FM学习从噪声到Boltzmann分布的连续变换（向量场）

应用阶段:
    ① 定位相变点:
        把训练好的模型直接用于大系统（128×128）
        生成不同温度的构型 → 计算物理量 → 找到相变温度
        （不需要重新训练！）
    
    ② 生成初始构型:
        用FM在大系统的目标温度生成构型
        这些构型已经接近平衡态
        从这些构型出发，只需很短的MC链即可测量
```

### 两个关键创新

**创新1：跨温度泛化**
- 训练时只在几个温度（如 $T=0.5, 1.0, 1.5, 2.0$）有数据
- 训练好的模型可以生成**任意温度**的构型（包括训练时没见过的温度）
- 原理：FM学习的是温度条件下的连续向量场，可以插值

**创新2：跨系统尺寸泛化**（最亮眼！）
- 在 $32\times32$（1024自旋）上训练
- 直接用于 $128\times128$（16384自旋）
- **不需要重新训练！**

**为什么可以跨尺寸？**
- 使用U-Net架构，基于卷积层，天然具有**平移等变性（Translation Equivariance）**
- 平移等变性意味着：输入平移多少，输出就平移多少；卷积核在**每个位置用同一组权重**
- 晶格物理系统具有**平移对称性**：每个格点上的哈密顿量形式完全相同
- 因此模型在32×32上学到的局域关联（如近邻自旋关联）在128×128的每个位置都同样适用
- 小系统学到的局域关联模式在大系统中同样适用
- 就像学会了识别一小块拼图的模式，就能拼出大拼图

> **"物理直觉"的含义**：因为物理是局域的且平移不变的，所以**故意选择**尊重这个对称性的网络架构（卷积/U-Net），而不是全连接网络（每个位置学不同的权重，会破坏平移对称性）。这个设计选择是跨尺寸泛化成立的关键前提。

**为什么 U-Net 预测速度/噪声（而非自旋构型），平移等变性仍然重要？**

U-Net 学习的是向量场 $v(\mathbf{x}, t, T)$，即 ODE $\frac{d\mathbf{x}}{dt} = v(\mathbf{x}, t, T)$ 中的速度。虽然预测的不是自旋构型本身，但**速度场继承了目标分布的对称性**：

```
物理哈密顿量平移不变 → 目标分布 p(x|T) 平移不变
→ 最优 ODE 路径在每个中间时刻 t 都平移等变
→ v*(平移(x), t, T) = 平移(v*(x, t, T))
→ U-Net（卷积）天然满足此性质 → 正确的归纳偏置
```

| ODE 时刻 t | $\mathbf{x}(t)$ 的状态 | 速度场的含义 | 平移等变性 |
|---|---|---|---|
| $t=0$ | 纯噪声（iid） | "噪声往哪个方向走" | ✅ 噪声每个位置独立同分布 |
| $t=0.5$ | 噪声+构型的混合体 | "继续向目标走" | ✅ 中间分布仍平移不变 |
| $t=1$ | 接近自旋构型 | "修正到 Boltzmann 分布" | ✅ 目标分布平移不变 |

**核心**：起始分布（高斯噪声）和终止分布（Boltzmann分布）都平移不变 → 连接它们的条件向量场必然平移等变 → 卷积架构是正确的参数化方式 → 32×32 学到的卷积核在 128×128 同样适用。

### Flow Matching vs 其他生成模型

| | NF | DM | FM |
|---|---|---|---|
| 精确概率 | ✅ | ❌ | ✅ |
| 训练稳定性 | ⚠️ | ✅ | ✅ |
| 采样速度 | 快 | 慢 | 中等 |
| 适合物理系统 | 可以 | 可以 | **最佳** |

FM的核心优势：既有NF的精确概率可计算性，又有DM的训练稳定性。而且FM学习的向量场是连续的，天然支持温度插值。

### 测试系统：2D XY模型

2D XY模型是一个连续自旋模型（自旋角度 $\theta_i \in [0, 2\pi)$），有一个著名的**KT相变**（Kosterlitz-Thouless transition）。

- 低温相：准长程有序（涡旋-反涡旋束缚对）
- 高温相：无序（自由涡旋）
- 相变温度 $T_{KT} \approx 0.893$（精确值已知）

### 结果

1. **相变点定位**：在小系统训练 → 准确预测大系统的相变温度
2. **初始构型质量**：FM生成的构型与长时间MC热化后的构型质量相当
3. **热化时间节省**：传统MC需要 $\sim 10^5$ 步热化，FM+短MC链只需 $\sim 10^2$ 步
4. **训练成本**：只需在小系统+稀疏温度点训练一次

### 与Lu 2021 (NiMC) 的对比

| | Lu 2021 (NiMC) | Lee & Wang 2026 (FM) |
|---|---|---|
| 生成模型 | VAE | Flow Matching |
| 训练数据 | 目标温度的MC样本 | 多个温度的MC样本 |
| 跨温度泛化 | ❌ 每个温度单独训练 | ✅ 训练一次，泛化到所有温度 |
| 跨尺寸泛化 | ❌ 每个尺寸单独训练 | ✅ 小系统训练，大系统使用 |
| 精确概率 | ❌ VAE不提供 | ✅ FM提供 |
| 物理系统 | 2D Ising + Hubbard | 2D XY |

### 局限性

- 只测试了2D XY模型（无挫系统），未测试自旋玻璃
- 跨尺寸泛化依赖于物理关联的局域性，对长程耦合的系统可能不适用
- FM生成的构型仍需短MC链修正
- U-Net架构的选择基于物理直觉（利用了晶格系统的平移对称性）

| **① Lu 2021 成功** | 目标系统简单（2D Ising只有两个模式）；NN只需学一个温度；NN不参与MC更新 |

| **③ Hunt-Smith 2023 成功** | 目标是低维连续分布（~10维）；动态重训练让DM逐步适应 |
| **④ Del Bono 2026 成功** | 退火框架中逐步训练（数据质量随温度渐变）；PA种群提供多样化训练数据；局部修正弥补NN不精确 |
| **⑤ Nakano 2026 成功** | QAOA天然倾向低能态（训练数据质量高）；只需近似低温分布；Metropolis修正偏差 |
| **⑥ Lee & Wang 2026 成功** | FM训练稳定+精确概率可计算；U-Net的平移等变性允许跨尺寸泛化；只测无挫系统 |

## 延伸讨论

### Q1：Flow Matching 能否迁移到退火框架（如 Del Bono 2026 的 GA）？

**原则上可以，但面临三大障碍。**

如果用 FM 替换 GA 中的 MADE：

| 方面 | MADE（当前） | FM（替换） | 评估 |
|------|-------------|-----------|------|
| 精确概率 $p(\mathbf{x})$ | ✅ | ✅ | 无问题 |
| 训练速度 | 1 epoch/温度 | 需~10-50 epoch/温度 | ❌ FM训练更慢 |
| 数据需求 | 少量种群即可 | 需要更多数据 | ❌ 种群可能不够 |
| **数据类型** | 离散 $\pm1$（Bernoulli） | 连续（需额外处理） | ❌ **最大障碍** |
| 采样速度 | 慢（逐自旋生成） | 中等（解ODE） | ✅ |
| 平移等变性 | 全连接，无 | U-Net 卷积 | ⚠️ 3D EA 耦合随机 |

**核心障碍**：

1. **离散性**：3D EA 自旋玻璃的自旋 $\pm1$ 是离散的，FM 天然处理连续空间。需要连续松弛等技巧，引入近似误差。
2. **训练开销**：MADE 只需 1 epoch/温度，FM 可能需要几十个 epoch。退火有数百个温度步 → 总训练时间可能不可接受。
3. **3D EA 的平移对称性不完全**：耦合 $J_{ij}$ 是随机的 → 哈密顿量不完全平移不变。U-Net 的平移等变性优势被削弱。

**但如果换到连续系统**（如 2D XY）+ 退火 → FM + GA 的组合**会很自然**：FM 天然处理连续角度，U-Net 平移等变性被充分利用。

### Q1.2：有没有"连续 + 阻挫"的系统？

**有！而且这恰好是 FM + GA 组合的最佳战场。**

本文档讨论的系统可以分为四个象限：

| | 无阻挫 | 有阻挫 |
|---|---|---|
| **离散** ($s_i = \pm 1$) | 2D Ising模型（论文①） | 3D EA自旋玻璃（论文②④⑤） |
| **连续** ($\theta_i \in [0, 2\pi)$) | 2D XY模型（论文⑥） | **XY自旋玻璃 / Heisenberg自旋玻璃** |

**连续阻挫系统的经典例子**：

| 系统 | 自旋类型 | 阻挫来源 | 难度 | 备注 |
|------|---------|---------|------|------|
| **XY自旋玻璃** | $\theta_i \in [0,2\pi)$ | 随机耦合 $J_{ij}$ | ⭐⭐⭐ | FM+GA的最佳候选 |
| **Heisenberg自旋玻璃** | 3D矢量（单位球面） | 随机耦合 $J_{ij}$ | ⭐⭐⭐ | 更高维的连续自由度 |
| **三角格XY反铁磁体** | $\theta_i \in [0,2\pi)$ | 三角格+反铁磁 | ⭐⭐ | 几何阻挫，但耦合均匀 |
| 全连接XY自旋玻璃 | $\theta_i \in [0,2\pi)$ | 随机全连接耦合 | ⭐⭐⭐ | SK模型的XY版本 |

**为什么 XY 自旋玻璃是 FM+GA 的最佳候选？**

```
XY自旋玻璃:
  ✅ 连续自旋 → FM 天然适配（直接输出角度速度场）
  ✅ 阻挫 → 需要全局移动（GA 的优势）
  ✅ 晶格结构 → U-Net 平移等变性可用（但不如无阻挫系统完美）
  ✅ 训练稳定 → FM 的 MSE 损失
  ✅ 精确概率 → FM 可计算，支持 Metropolis 准则
```

这实际上是**当前文献中的一个空白**：目前没有论文将 Flow Matching 用于阻挫系统的采样/优化。这是一个有潜力的研究方向。

### Q1.2.5：几何阻挫 vs 随机阻挫——平移对称性的关键区别

**极其重要的观察**：阻挫的来源决定了平移对称性是否被破坏。

| | 自旋玻璃（EA/SK） | 三角格反铁磁体 | Kagome反铁磁体 |
|---|---|---|---|
| 阻挫来源 | **随机耦合** $J_{ij}$ | **三角形几何** | **Kagome几何** |
| 耦合是否均匀 | ❌ 每条边不同 | ✅ 处处相同 | ✅ 处处相同 |
| **平移对称性** | ❌ **被破坏** | ✅ **完整保留** | ✅ **完整保留** |
| U-Net适用性 | ⚠️ 削弱 | ✅ **完美** | ✅ **完美** |

**为什么三角格/Kagome保留平移对称性？**

以三角格反铁磁XY模型为例：

$$H = J\sum_{\langle i,j \rangle} \cos(\theta_i - \theta_j), \quad J > 0$$

- 耦合 $J$ **处处相同**（没有随机性）
- 阻挫来自**三角形的几何**：三个自旋两两反铁磁耦合，无法同时满足所有边
- 哈密顿量在晶格平移下**完全不变**
- → U-Net 的平移等变性被**完全利用**！

```
三角格上的阻挫（反铁磁 J > 0）:
    θ₁ ─── θ₂
     \   /
      θ₃
    
    J > 0: 相邻自旋要反平行
    θ₁ ≠ θ₂, θ₂ ≠ θ₃, θ₃ ≠ θ₁
    但 θ₁ ≠ θ₂ 且 θ₂ ≠ θ₃ → θ₁ ≈ θ₃ → 与 θ₃ ≠ θ₁ 矛盾！
    
    → 几何阻挫！但耦合处处相同 → 平移对称性完整
```

**结论：三角格/Kagome XY反铁磁体是FMA的最优系统**

```
三角格/Kagome XY反铁磁体:
  ✅ 连续自旋 → FM 天然适配
  ✅ 几何阻挫 → 物理上有意义且有趣（自旋液体、冰规则等）
  ✅ 平移对称性完整 → U-Net 的归纳偏置被完全利用
  ✅ 可跨尺寸泛化 → 小系统训练，大系统使用
  ✅ 训练稳定 → FM 的 MSE 损失
  ✅ 精确概率 → FM 可计算，支持 Metropolis 准则
```

> **关于 warm-start**：相邻温度的 Boltzmann 分布相近 → 上一温度的 FM 模型参数是下一温度的良好初始化 → 收敛快。

### Q1.3：FMA（Flow Matching Annealing）的完整流程设计

**目标**：将 Flow Matching 与退火框架结合，专为连续阻挫系统（如 XY 自旋玻璃）设计。

#### FMA 算法流程

```
Flow Matching Annealing (FMA) — 针对 XY 自旋玻璃

初始化:
    生成 R₀ 个随机角度构型（θ_i ∈ [0, 2π)），高温 T_high
    初始化 FM 模型（U-Net，随机参数）

for T = T_high → T_low (共 θ 个温度):
    
    ① 全局移动（FM 提议）:
       对种群中每个构型:
           a. 采样噪声 ε ~ N(0, I)
           b. 解 ODE: dθ/dt = v_φ(θ, t, T), t: 0→1
              得到提议构型 θ'
           c. 计算精确概率:
              log p_FM(θ') = log p₀(ε) - ∫₀¹ tr(∂v_φ/∂θ) dt
              （用 Hutchinson 迹估计，需几次前向传播）
           d. Metropolis 接受率:
              A = min{1, [π(θ')/π(θ)] × [p_FM(θ)/p_FM(θ')]}
           e. 以概率 A 接受 → 用 θ' 替换当前构型
       
       用当前种群构型训练 FM（warm-start，K 个 epoch）
    
    ② 局部移动（角度微扰）:
       对种群中每个构型:
           for step = 1 to θ_l:
               随机选一个自旋 i
               角度微调: θ_i → θ_i + Δθ  (Δθ 从均匀分布采样)
               Metropolis 接受/拒绝
    
    ③ 重采样（与 PA/GA 相同）:
       根据 Boltzmann 权重复制/淘汰构型
       种群大小保持 ~R₀

输出: 种群中能量最低的构型（优化）或测量物理量（采样）
```

#### FMA 中 FM 的训练细节

```
每温度的训练步骤（warm-start）:

输入: 当前种群的 R₀ 个构型 {θ⁽¹⁾, ..., θ⁽ᴿ⁾}（已标签"好"）
      上一温度的 FM 模型参数 φ_{T+ΔT}（warm-start）

for epoch = 1 to K:  (K = 1~5)
    for each 构型 θ⁽ⁱ⁾ in minibatch:
        1. 采样 t ~ U[0,1]
        2. 采样噪声 ε ~ N(0, I)
        3. 插值: θ_t = (1-t)·ε + t·θ⁽ⁱ⁾
        4. 计算目标速度: u = θ⁽ⁱ⁾ - ε
        5. 前向传播: v_φ(θ_t, t, T)
        6. 损失: L = ||v_φ - u||²
    更新 φ ← φ - η·∇L
    
输出: 更新后的 FM 模型参数 φ_T
```

#### FMA vs GA 对比

| 方面 | GA（MADE + 退火） | FMA（FM + 退火） |
|------|-------------------|-------------------|
| 目标系统 | 离散（$s_i = \pm 1$） | **连续**（$\theta_i \in [0, 2\pi)$） |
| 生成模型 | MADE（全连接） | FM（U-Net 卷积） |
| 全局采样方式 | 自回归（逐自旋） | 解 ODE（并行） |
| 精确概率 | ✅ 一次前向传播 | ✅ Hutchinson 迹估计 |
| 每温度训练 | 1 epoch | K = 1~5 epoch（warm-start） |
| 平移等变性 | ❌ 全连接无 | ✅ U-Net 卷积 |
| 采样速度 | 慢（$O(N)$ 步自回归） | 中等（$O(S)$ 步 ODE，$S \sim 10$~100） |

#### FMA 的优势：为什么 FM 在退火框架中可能更高效

1. **温度条件输入**：FM 接收温度 $T$ 作为输入 → 从 $T$ 到 $T-\Delta T$ 时，只需微调而非从头训练
2. **Warm-start**：用 $T$ 的模型初始化 $T-\Delta T$ → 相邻温度的分布相似 → 收敛快
3. **并行采样**：ODE 求解可以批量并行（GPU），而 MADE 的自回归采样是严格串行的
4. **U-Net 的归纳偏置**：即使随机耦合削弱了平移等变性，局域关联仍然有用

#### FMA 的剩余挑战

| 挑战 | 严重程度 | 可能的解决方案 |
|------|---------|---------------|
| **训练开销** | ⚠️ 主要问题 | warm-start + 温度条件输入 → 可能只需1-3 epoch |
| 精确概率计算开销 | ⚠️ 中等 | Hutchinson 迹估计需~10次前向传播；可用低阶近似 |
| ODE 求解开销 | ⚠️ 中等 | 自适应步长求解器；或用更少的 ODE 步数 |
| 随机耦合削弱平移等变性 | ⚠️ 轻微 | **选择三角格/Kagome系统可完全避免**（几何阻挫保留平移对称性） |

#### 结论：问题是否只剩训练开销？

**不完全是**。训练开销是主要问题，但还有两个次要问题：

1. **精确概率的计算开销**（Hutchinson 迹估计）——增加了每步 Metropolis 的成本
2. **ODE 采样开销**——需要多步数值积分

但这些问题都有成熟的解决方案（低阶近似、自适应求解器等），且在连续系统中不存在根本性障碍。**与 GA 在离散系统上面临的"离散性"这个根本障碍不同，FMA 在连续系统上面临的都是工程层面的优化问题。**

### Q1.5：FM 的神经网络本质上也在学习"去噪"，那它不就是另一种形式的 MADE 吗？

**对，本质上都是"神经网络学习数据分布"，但关键差异在于输出空间。**

```
MADE:  输入 x → 输出 p(s_i = +1 | s_{<i})  → Bernoulli 概率（离散）
FM:    输入 x_t, t → 输出 v(x_t, t)          → 连续速度（连续）
```

两者都是神经网络，都在学习数据分布的某种表示。但：

| | MADE | FM |
|---|---|---|
| 输出 | 每个自旋的 Bernoulli 概率 | 整个构型的连续速度场 |
| 天然适配 | **离散**数据（$\pm 1$） | **连续**数据（角度、像素值） |
| 处理离散的方式 | 直接（输出就是概率） | 间接（需要连续松弛，再离散化） |
| 在 GA 中替换 | 当前方案 | 需要额外处理离散性 |

**所以本质上 FM 确实可以替代 MADE 的角色**——都是"学习分布 + 提供提议"——但替换的难点不在于学习范式，而在于**数据类型适配**：FM 在连续空间很自然，但在离散空间需要额外的松弛技巧（如 Gumbel-Softmax、连续近似等），这会引入近似误差。

### Q2：Flow Matching 需不需要 gradient-free 优化？

**不需要。FM 用标准梯度下降（Adam）训练，损失函数是简单的 MSE。**

```
FM 训练目标（Conditional Flow Matching）:
    L = E_{t, x₀, x₁} || v_θ(x_t, t) - (x₁ - x₀) ||²

    x₀ ~ N(0, I)           （噪声）
    x₁ ~ 训练数据           （真实构型）
    x_t = (1-t)·x₀ + t·x₁  （线性插值）
    v_θ = U-Net 输出         （预测速度）

    → 简单的回归问题，完全可微，Adam 即可优化
```

**各生成模型的训练难度对比**：

| 方法 | 训练方式 | gradient-free？ |
|------|---------|---------------|
| MADE（MLE训练） | 最大化对数似然，标准梯度 | ❌ |
| MADE（变分训练） | REINFORCE（高方差梯度估计） | ⚠️ 梯度困难 |
| DM（扩散模型） | 去噪 MSE，标准梯度 | ❌ |
| **FM** | **速度场 MSE，标准梯度** | **❌ 最简单** |
| QAOA 参数优化 | 量子电路参数 | ⚠️ 有时需要 |

FM 的训练是这几种生成模型中**最简单的之一**——损失解析、低方差、完全可微。
